# H9: 4.1.0 ships before format 1.0 is frozen, as a testers-only preview

- Asked: 2026-10-21, `ROADMAP.md` "What needs the owner" (H9); put to the owner again on
  2026-10-27 by REL-1 step 3, because V (the format freeze) is parked.
- Answer: 2026-10-27, relayed by the roadmap session: 4.1.0 is a testers-only preview, with
  "preview" in About and the capsule set named 1.0-draft. V comes next, and it keeps testers'
  projects opening in 1.0.

## The rule

1. The release is `4.1.0-preview` (`[workspace.package] version`, tag `v4.1.0-preview`). About
   shows "Version 4.1.0-preview (<commit>)", and the installers' file names carry the same
   version.
2. It goes to named testers only, not to the download page.
3. When V freezes the format, the sample projects of this preview are its capsule set
   `1.0-draft`. V's older-reader job keeps every project 4.1.0-preview wrote opening in 1.0, so
   testers never have to import their work again.

## Effect for translators

Testers can install the app and work in it now. Their projects keep opening when 1.0 ships.

## Unblocks and changes

- REL-1 no longer waits for V. V is the next card after REL-1, with the `1.0-draft` capsule set
  added to its scope.
- `ROADMAP.md` H9's "If not frozen" branch is the one taken.
