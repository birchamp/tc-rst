# H22: smaller choices of the storage delta (all four parts)

- Asked: 2026-10-22, by the roadmap session, in conversation with the owner.
- Answer: "1. I'm not sure 2. agree 3. agree 4. agree". After an example of part 1 (options A, ask
  once with "Bring it back"; B, bring it back automatically): "I think A".

## Part 1: work found only in a file the app wrote (delta Q2, option A)

When a save is missing from the app's own record (another program removed or damaged a record
file) but a book file the app wrote still holds it, the app keeps the text and asks once: "Some
recent work was missing from this project's records. Bring it back?" "Bring it back" restores it
through the normal import; a clash with newer work goes to the conflict review. Nothing comes back
on its own. The same applies to every kind of file the app writes.

## Part 2: the second file's name under "Keep both" (delta Q4)

`<stem>-<Door43 user>.<ext>`, for example `jon_01-Juan.wav`, because project paths cannot hold
spaces.

## Part 3: a book edited by hand inside a USB exchange file (delta Q6, the simpler choice)

Treated like an edit made with Door43's own tools (`2026-10-22-H18.md`): the receiving app keeps
its own text and says once, for example, "Juan's file holds a changed Titus that was not made in
translationCore. It was not taken in; the file on the stick still has it." Nothing is kept as a
copy in the project and nothing is offered for import. Nothing is lost, because the exchange file
is never changed.

## Part 4: small behaviours (delta Q7 and D1's merge)

- D1 may merge while its step for the one-line notices of other generated files is still open;
  that step finishes after.
- No Undo after an import; History keeps every version and the conflict review handles mistakes.
- A project opened read-only keeps no copy and asks nothing; it shows a notice.
- With a full disk, a changed file is left exactly as it is until the app can make its copy.
- A change only of line endings asks nothing; it keeps a copy and shows the notice.
- Not shown to the owner, so not ruled: the delta's other Q7 items (a file that cannot be read is
  asked with "Not now" only; the question is raised when the app finds the change while it has
  focus; a book file for a book the project lacks is moved out of `ingredients/` on "Not now").
  They follow the delta until the owner says otherwise.
