## Questions for the owner

1. At 1024 px the four buttons squeeze the project's name into a narrow column (01). Keep the
   two USB buttons on the card, or put them under one "Exchange" menu beside Share on Door43?
   Recommendation: one menu, "Save or receive work by USB", so the card's row stays as tC4's.
2. After one verse from B, A's sheet says "2 changes were received" (13): B's open also wrote the
   project's resource pins, and a receive counts them as a sync does. Should pin bookkeeping be
   left out of the count, as a device's profile already is? Recommendation: leave it out.
3. B has no Door43 name, so A's sheet says "Teammate 1" (13). Fine for a computer that never
   signed in, or should the file carry the sender's name from the export dialog?
   Recommendation: keep "Teammate 1" (the Door43 name is shown once the sender signs in, #680).
