# H18: edits made with Door43's own tools on a team's project repository

- Asked: 2026-10-22, by the roadmap session, in conversation with the owner.
- Options: A, merge them (STORAGE §11.2 as designed); B, unsupported with a notice; C, unsupported
  with Import offered.
- Answer: "B".

## The rule

An edit made on Door43 with gatewayEdit, tcCreate, the web editor, or any tool other than
translationCore, is unsupported, the same as a project folder pushed by another tool
(`2026-10-21-outside-edits.md` rule 7). translationCore's sync keeps the project's own text and
does not merge the edit. The app tells the team once that a file was changed outside
translationCore, by whom, and that the version is kept in Door43's history. To use it, a person
downloads the file and runs "Update a book".

## Effect for translators

Nothing is lost: the edit stays in Door43's history. A web fix reaches the project only through
"Update a book".
