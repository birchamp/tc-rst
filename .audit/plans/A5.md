  `RequestId`. The reply cache keeps refusals too (A4b), so a retry after a failed Apply mints a

  language while its own dialog is open, and §6.9 says a switch updates text in place and
  remounts nothing; React re-renders the same nodes with new strings. These DS props take plain

## 6. Traps found while planning

1. **The shared tC4 checkout has no `node_modules` and no `public/help`.** §0 step 4. Never run
   `npm ci` or `fetch-help.mjs` in it.
2. **`home()` waits for project cards.** Without D6 every A5 capture and sequence times out in the
   Rust environment.
3. **Listing A5 in `units.json` makes the gate demand every A5 layer at once**, the `license`
   gallery case included (§7.4 gives its DOM to A5), and a capture by A5 fails while A5 is not
   listed. Add the id, the captures and the report in one commit.
4. **A scoped behaviour step without its scope fails the row** (`dom.rs:318-323`), so D7 comes
   before the sequences.
5. **Static DS text props break the preview.** `Modal.close_label`, `Field.label/hint` and the
   Select's labels are plain strings; under a preview they keep the old language and the M16
   sequence differs from tC4. `Content` (a Modal title) is reactive only when its closure returns
   a closure: `title = move || move || t(keys::language::TITLE, &[])`, not `move || t(…)` (a
   `Content::View` is called once, `ds/mod.rs:105-111`). Check the title changes under a preview
   before you capture.
6. **Focus that leaves the menu or the dialog for Home's content** lands on different elements on
   the two sides until B2 (the stand-in's `<select>` against Home's buttons); keep such steps out
   of the sequences (§3 10c).
7. **`ServerState.restarted` stays `true`.** Watch `instance` for the restart (D15).
8. **The navigation gate never runs on the restart path**, and always runs on every other exit.
   A `go`/`back_to_projects` that skips it can leave a failed save behind silently.
9. **The probe page must stay outside the App.** If the probe were `MainView`'s content, D15's
   "go Home" would unmount its fields and break A4b's restart cases (they expect
   `Held(Hold::Restarted)` with the editor on screen).
10. **`vendored_assets.rs` repeats `vendor-tc4.sh`'s path mapping**; change both for `about/`.
11. **`include_str!` paths** are relative to the source file; from `src/views/account_menu.rs` the
    vendored files are `../../assets/about/LICENSE`.
12. **The copyright line keeps its inner double space** ("2017 - 2026  unfoldingWord"); trim the
    ends only, as tC4's `trim()`.
13. **JavaScript's `\s` and `trim()` are not Rust's whitespace** (U+0085, U+FEFF); port the set.
14. **`env.load` resets prefs** (`test/reset`): a "fresh session" in app-language b/c is a page
    reload, not `env.load`.
15. **The feedback mask's rectangle is tC4's** (59 px tall). B2's pixel capture needs the Rust
    attachment to be as short as tC4's: after `test/reset` the report log is empty, so it is
    "no Report" on both sides; keep it that way (do not add reports at start that survive
    `test/reset`). Tell B2 in the row note.
16. **`help` runs in a frame whose loads need the token.** It works in the shell (filter on
    `/help/*`), in Playwright (`extraHTTPHeaders`) and in A4a's smoke (its route adds the header
    outside `/api/`); the shim must not add headers itself.
17. **wasm-bindgen snippets** land in `snippets/<crate>-<hash>/app/help-shim.js` beside the glue;
    `build-app.sh` copies the whole bindgen output, so nothing else is needed. The extern block must
    be under `cfg(all(target_arch = "wasm32", feature = "app"))` so the host and gallery builds
    never see it.
18. **`AppHeader`'s project props are read once**; rebuild it on a project change, and remember
    the right slot (the account menu) is rebuilt with it.
19. **The behaviour recorder waits 350 ms per step**; the menu's 10-frame focus hold and the
    Layer's 240 ms motion fit, but record twice on both sides and require equal files.
20. **tC4's `Tab` in the menu** does not `preventDefault`: the browser moves the focus first,
    then the menu closes; the DS Layer's focus restore decides where focus ends. Assert only that
    the panel closes (trap 6).
21. **M16's Select is disabled while saving, and the DS Select accepts a row click while
    disabled** (TC4-ISSUES §1 row 13). The dialog's own guard (`select` does nothing while
    `locked`, tC4 line 362) keeps M16 correct; the DS fix is someone else's "now" item.
22. **`about-version` comes from the wasm's constants**, which equal the server's (a different
    commit reloads the page, §3.10); it needs no request, as tC4's About sends none (internet-consent i).
23. **The A4a smoke's "no request after boot"** counts the app's requests; the M16 preview, the
    menu, About and License must send none. Help's frame loads and Feedback's `feedback/compose`
    are requests of their own actions, not of boot.
24. **Help pages name tC4's build** ("Every page describes build b04c70f … v4.0.0-rc.1"). They stay
    byte for byte (AD29, and the `help` baseline needs them); DELTA-10-19 Q31 asks the owner about
    this banner for the rc.2 pages, and it applies to these too: say so in the final answer.
