## Findings fixed during verification

- Cancelling a real section draft originally closed only the browser card. The durable CAS
  path now waits for earlier draft calls, retains errors and text for Retry, and preserves
  independent offers and later input. Declared difference: Cancel waits for durable removal;
  tC4's local card closes immediately. PLAN records the translator-facing reason.
- A delayed pre-save section Draft could arrive after a clean Ack and restore obsolete text
  as an offer. Clean Acks capture the exact active, pending, completed and failed draft bodies;
  cleanup drains their lane and CAS-removes those bodies asynchronously. Saves never wait
  behind draft I/O. Later text, time or tokens cannot match the captured removal. Cleanup is
  best effort if the server or disk refuses; the confirmed saved version remains intact.
- Strict save counts found eager decoding of every device profile even when a save created
  no conflicts. `wire::write::new_conflicts` now returns the empty list before label
  derivation. The unchanged counters then pass on memory and real storage at both scales.
