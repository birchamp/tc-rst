## Rules kept

- A link is never lost: a save that fails or is refused leaves the session unsaved and tries
  again; leaving a verse, replacing it, closing it and quitting save first, and a failed save
  keeps the person where they are (the navigation gate).
- Nothing in `align/index`, `open` or a click writes the project; only the save does, as one
  `SaveAlignment` command with the tokens of what the screen showed.
- A view the server could not build is stated (Blocked), never read as an empty verse.
