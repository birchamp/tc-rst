# INV-ATOMIC-WRITES: the source files that may call a filesystem mutator, and why.
# One line per file: path<TAB>reason. A file here with no write call left fails as stale.
crates/tc-store/src/vfs.rs	the real filesystem under tc-store's atomic helpers: the one place project files are written
crates/tc-resources/src/store.rs	the resource store in app data (installs, its index, staging folders), not a project
crates/tc-resources/src/held.rs	the resource store's rename and removal, retried while a scanner holds a file
crates/tc-door43/src/download.rs	a downloaded zip in the caller's download folder, removed once used
crates/tc-door43-fake/src/git.rs	the fake Door43 server's own bare repositories, for tests only
crates/tc-app/src/app.rs	creates app data, and the projects folder itself on first launch; no project file
crates/tc-app/src/bundle.rs	the installer bundle's BUNDLE-MANIFEST.json, written atomically (temp file, fsync, rename)
crates/tc-app/src/create.rs	removes an uploaded USFM file from app data once taken
crates/tc-app/src/fixes.rs	removes a sideloaded resource file from app data once taken
crates/tc-app/src/hooks.rs	test hooks only: app data's test-hooks folder
crates/tc-server/src/applock.rs	the app lock that keeps one instance per computer, in app data
crates/tc-server/src/lib.rs	empties and creates the server's per-run folders in app data
crates/tc-server/src/uploads.rs	uploaded files in app data, renamed into place and removed
crates/tc4/src/lib.rs	creates the app data folder at start
crates/tc-store/src/fault.rs	FaultFs's mirror: the real folder beside the model where libgit2 keeps a test project's .git, made, copied and removed for tests
crates/tc-store/src/git.rs	removes git's stale lock and temporary pack files: git's own files, not a project file
crates/tc-store/src/history.rs	moves a broken .git aside into .tc (G4 rebuild): git's own files, kept, not a project file
crates/tc-store/src/repack.rs	removes loose git objects a pack now holds, and their empty folders: git's own files, not a project file
crates/tc-sync/src/exchange.rs	the exchange file an export writes to the folder the person chose (a USB stick), under a temporary name, then renamed; no project file
crates/tc-app/src/export.rs	an export's file in the server's downloads folder in app data, renamed into the registry; never a project file
