Translation help

This page stands in for one of tC4's help pages. It has its own style sheet and pictures, so a frame that shows it makes the browser load three kinds of request by itself.

Translators check each verse against the original text. They look at every note and every word in the list, decide whether the translation is right, and record the decision. When the translation needs work, they change the verse and check it again. The help explains each step, with examples in the gateway language and pictures of the screens.
